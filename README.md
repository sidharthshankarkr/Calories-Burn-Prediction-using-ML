# Calories Burn Prediction using Machine Learning

## 📌 Project Overview
The Calories Burn Prediction project is a beginner-friendly Machine Learning project developed using Python.  
The main objective of this project is to predict the number of calories burned by a person during exercise based on factors such as:

- Age
- Weight
- Exercise Duration

This project uses the **Linear Regression Algorithm** to make predictions.

---

# 🎯 Objectives
- To understand the basics of Machine Learning
- To learn how prediction models work
- To predict calories burned using user inputs
- To build a simple real-life useful project

# 📂 Dataset Information

The dataset contains the following columns:

| Column Name | Description |
|---|---|
| Age | Age of the person |
| Weight | Weight in kilograms |
| Duration | Exercise duration in minutes |
| Calories | Calories burned |

```text
Enter Age: 21
Enter Weight (kg): 60
Enter Exercise Duration (minutes): 45

Estimated Calories Burned: 185.45
```
